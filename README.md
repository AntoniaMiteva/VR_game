# Ехото на Артефакта (Echoes of the Artifact)

## Описание
„Ехото на Артефакта“ е VR игра, разработена с Unreal Engine 5 за устройства Meta Quest.  
Играчът попада в интерактивен свят, в който трябва да открие и събере изгубените части на мистериозен артефакт, разпръснати из различни исторически епохи.

Играта комбинира виртуална реалност, исторически среди и логически пъзели, които превръщат играча в активен участник в приключението.

## Основни функции
- Виртуална реалност (VR) управление чрез Meta Quest контролери  
- Интерактивни исторически нива  
- Логически пъзели и загадки  
- Портали между различни епохи  
- Взаимодействие с обекти в триизмерна среда  

## Технологии
- Unreal Engine 5  
- Blueprint Visual Scripting  
- OpenXR  
- Meta Quest VR  

## Инсталиране
1. Изтеглете `.apk` файла от Itch.io  
2. Свържете Meta Quest устройството в Developer Mode  
3. Инсталирайте приложението  
4. Стартирайте го от секцията **Unknown Sources**
